# 📱 QR Code Generator Pro (Single File PWA)

> **พัฒนาโดย:** พว.วิษณุกรณ์ โอยา  
> **เวอร์ชัน:** 3.0 (Single File Edition)  
> **วันที่เผยแพร่:** 26 มกราคม 2569

เว็บแอปพลิเคชันสำหรับสร้าง QR Code ดีไซน์สวย ทันสมัย (Glassmorphism) ใช้งานง่าย รองรับการทำงานแบบ **PWA (Progressive Web App)** ที่เขียนโค้ดทั้งหมดรวมจบในไฟล์ HTML เพียงไฟล์เดียว สะดวกต่อการนำไปใช้งานและส่งต่อ

## ✨ ฟีเจอร์เด่น (Key Features)

* **🎨 Modern UI:** ดีไซน์กระจกฝ้า (Glassmorphism) สวยงาม สะอาดตา ด้วย Tailwind CSS
* **🚀 Single File Architecture:** รวม HTML, CSS, JS และ Manifest ไว้ในไฟล์เดียว ไม่ต้องแยกโฟลเดอร์
* **📱 PWA Ready:** รองรับการติดตั้งเป็นแอปพลิเคชันบนมือถือ (iOS/Android) และคอมพิวเตอร์
* **⚙️ Fully Customizable:**
    * ปรับความละเอียดภาพได้ (ตั้งแต่ 200px ถึง 1000px)
    * เลือกสี QR Code และสีพื้นหลังได้ตามธีมองค์กร
    * ปรับขนาดตัวอักษรได้
* **🔤 Custom Label:** รองรับการใส่ข้อความกำกับใต้ภาพ (เช่น ชื่อ, เบอร์โทร, เว็บไซต์)
* **💾 High Quality Export:** ดาวน์โหลดไฟล์ผลลัพธ์เป็น .PNG ความละเอียดสูง

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Tailwind CSS (CDN)
* **Library:** QRCode.js (CDN)
* **Typography:** Google Fonts (Kanit)

## 🚀 วิธีเริ่มต้นใช้งาน (Getting Started)

เนื่องจากโปรเจกต์นี้ถูกออกแบบมาเป็น **Single File** การใช้งานจึงง่ายมาก:

1.  ดาวน์โหลดไฟล์ `index.html`
2.  เปิดไฟล์ด้วย Web Browser (Chrome, Safari, Edge) เพื่อใช้งานได้ทันที

### 📲 การติดตั้งเป็นแอป (PWA)
เพื่อให้ฟีเจอร์ปุ่ม **"ติดตั้งแอป"** ทำงาน หรือต้องการใช้งานแบบ Offline:
1.  นำไฟล์ `index.html` ไปวางบน Web Server ที่รองรับ **HTTPS**
2.  หรืออัปโหลดขึ้น **GitHub Pages**, **Vercel**, หรือ **Netlify** (แนะนำวิธีนี้ เพราะฟรีและมี SSL ให้)

## 📝 วิธีการใช้งาน

1.  **ระบุข้อมูล:** พิมพ์ URL หรือข้อความที่ต้องการในช่องระบุข้อมูล
2.  **ปรับแต่ง:** เลือกขนาดภาพ, ขนาดตัวอักษร, และคู่สีที่ต้องการ
3.  **สร้าง:** กดปุ่ม "สร้าง QR Code" เพื่อดูตัวอย่างจริง
4.  **บันทึก:** ตรวจสอบความถูกต้อง แล้วกด "ดาวน์โหลดรูปภาพ" เพื่อนำไปใช้งาน
